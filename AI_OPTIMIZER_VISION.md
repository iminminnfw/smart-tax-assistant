| **Hybrid** | "ประหยัดภาษีสูงสุด + ซื้อบ้านใน 2 ปี" | หาจุดสมดุลที่ตอบโจทย์ทั้งสอง |

### Goal Understanding Engine

```python
# AI จะ Parse เป้าหมายจากภาษาธรรมชาติ

class GoalParser:
    """
    แปลงเป้าหมายจากภาษาพูดเป็น Structured Goal
    """

    def parse(self, user_input: str) -> StructuredGoal:
        # ตัวอย่าง Input: "อยากประหยัดภาษีสัก 50,000 แต่ต้องมีเงินเหลือไว้ดาวน์บ้าน 1 ล้านปลายปีหน้า"

        return StructuredGoal(
            primary_goal=GoalType.TAX_SAVING,
            target_amount=50000,
            constraints=[
                Constraint(type="minimum_cash", amount=1000000, deadline="2025-12"),
            ],
            priority="balanced"  # tax saving vs liquidity
        )
```

## Implementation Priority

### Phase 1: Foundation (สำคัญที่สุด)
1. **Profile Integration** - ดึงข้อมูลผู้ใช้จากระบบมาใช้
2. **Goal Parser** - แปลงเป้าหมายจากภาษาธรรมชาติ
3. **Dynamic Scenario Generator** - สร้าง scenarios แบบ personalized

### Phase 2: SEC Integration
4. **Fund Recommendation** - แนะนำกองทุนจาก SEC data
5. **NAV Display** - แสดงราคาล่าสุด
6. **Performance Charts** - กราฟผลตอบแทนย้อนหลัง

### Phase 3: AI Enhancement
7. **Chat Interface** - AI Advisor แบบถาม-ตอบ
8. **What-If Simulator** - ปรับตัวแปรดูผลลัพธ์
9. **Smart Alerts** - แจ้งเตือนอัจฉริยะ

### Phase 4: Polish
10. **Calendar Integration** - ซิงค์กับ Google Calendar
11. **Tax Projection** - คาดการณ์ภาษีหลายปี
12. **Health Check** - ตรวจสุขภาพการเงินประจำปี

## Summary

AI Tax Optimizer ที่โดดเด่นต้องมี:

1. **รู้จักผู้ใช้จริงๆ** - ไม่ใช่แค่ถามอายุแล้วจบ แต่วิเคราะห์ Profile ทั้งหมด
2. **เข้าใจเป้าหมาย** - รับ Input เป็นภาษาธรรมชาติ ไม่ใช่ให้เลือกจาก dropdown
3. **ใช้ข้อมูลจริง** - SEC API ให้ข้อมูลกองทุนล่าสุด ไม่ใช่ตัวเลขสมมติ
4. **อธิบายได้** - บอกเหตุผลว่าทำไมถึงแนะนำแบบนี้
5. **ติดตามได้** - Timeline, Calendar, Alerts ช่วยให้ทำตามแผน

**Key Message:**
> "ไม่ใช่แค่เครื่องคิดเลขภาษี แต่เป็น AI Financial Advisor ตัวจริงที่รู้จักคุณ"
